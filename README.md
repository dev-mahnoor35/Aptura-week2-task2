A modern, high-performance, dark-themed analytics and system preferences dashboard designed for frontend monitoring, traffic visualization, and environment management.

---

## 🌟 Key Features

- **SEO & Traffic Analytics Dashboard:** Real-time visitor distribution, geographic server load metrics, and timeline traffic charts.
- **Extended System Analytics:** Comprehensive throughput visuals powered by Chart.js (Line, Bar, and Polar charts).
- **Interactive Controls:** Timeframe filter switches (Live, 24h, 7d), active server node monitors, and hardware utilization meters.
- **Enterprise Preferences & Settings:** Tabbed preferences layout, API key toggles, 2FA status, and integration management cards.
- **Responsive & Dynamic UI:** Built with custom CSS CSS variables, smooth card hover animations, and subtle glow accents.

---

## 🛠 Tech Stack

- **Frontend Core:** HTML5, CSS3, JavaScript (ES6+)
- **Data Visualization:** [Chart.js](https://www.chartjs.org/)
- **Icons & Typography:** [FontAwesome 6](https://fontawesome.com/)
- **Version Control & Hosting:** Git, GitHub Pages
